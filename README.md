## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Format Support** — Read comics in CBR, CBZ, TAR, ZIP, RAR, and ARJ formats, plus direct image reading from folders.
- **Image Compatibility** — Enjoy images in JPEG, GIF, PNG, TIFF, and BMP formats.
- **User-Friendly Navigation** — Turn pages easily using mouse or keyboard controls.
- **Fullscreen Mode** — Immerse yourself in your comics with a distraction-free reading experience.
- **Animations for Page Turns** — Experience smooth transitions between pages for a more engaging read.

### Advanced Features:
- **Magnifying Glass** — Zoom in on images for detailed viewing.
- **Save Individual Pages** — Keep your favorite comic pages for later reference.
- **Bookmarking** — Quickly save your place in any comic for easy access.
- **Library Management** — Import/export comic covers and edit file names directly within the application.
